# Hangman Game (Console)

A terminal-based Hangman game written in Python.

## How to run
1. Install Python 
2. Keep hangman.py and words.txt in the same folder
3. Run: python hangman.py

## Features
- Random word chosen from a 10,000-word English list
- ASCII gallows art that updates on each wrong guess
- 6 mistakes allowed
- Repeated guesses are not penalized
- Play again option
